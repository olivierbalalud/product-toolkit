**Use Case:** Meal ordering
**Actor:** User
**Description:** The user uses the system to order food.
1. User logs in with username and password.
2. User clicks on the "Menu" tab.
3. System loads the menu from the database.
4. User ticks the items wanted and clicks "Add to cart".
5. If the user wants another meal he goes back to step 2, otherwise he clicks "Checkout".
6. System calculates the price.
7. User picks a time in the dropdown.
8. System saves the order in the ORDERS table and sends an email.
9. User logs out.
