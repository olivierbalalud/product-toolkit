**UC:** Reservation module
**Actor:** System
1. Clerk clicks "New Reservation" in the top menu.
2. The reservation form opens.
3. Name, email and phone are typed.
4. The calendar widget is used to pick dates.
5. System runs the availability query and shows the rooms grid.
6. A room is picked, price is calculated with tax, and the deposit is charged through the Stripe API if needed.
7. Reservation saved.
