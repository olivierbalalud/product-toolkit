**Use case:** Expense Report Portlet
Paul Tester (Employee) submits a report for a business trip; Mary Manager (Manager) approves it.
1. Log in as Paul Tester.
2. Add the Expense Report portlet to your page.
3. Click the link to add a new expense report.
4. Enter description, amount and date; click to add more rows.
5. Save the report, go back to the report summary, click the report ID.
6. Click Submit; the status becomes Pending.
7. Log in as Mary Manager, add the portlet, click the report ID.
8. Click Approve.
