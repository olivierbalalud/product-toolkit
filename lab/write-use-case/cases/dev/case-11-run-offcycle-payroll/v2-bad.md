**Title:** Pay a Contractor  
**Actor:** Admin  
**Description:**  
Go to the payroll screen. Click the checkbox next to the contractors who did work this week. Enter the money they are owed into the box. Hit continue. The system checks if the user is allowed to do this. Then the system calculates the money. If it looks good, click the green "Submit Payroll" button. The system will send the money to their bank accounts.
