**Title:** Make a Blend with friends  
**Actor:** Spotify Listener  
**Description:**  
The user taps the Search bar, then goes to the "Made For You" card. They scroll down to "Create a Blend" and tap the big plus icon. A green screen appears with nice animations. The user taps "Invite" which brings up the standard iOS share sheet. The user texts the link to their friend. When the friend clicks the link, the app opens. The app calculates their compatibility using machine learning algorithms. The playlist shows up. Both people can now listen to the music together.
