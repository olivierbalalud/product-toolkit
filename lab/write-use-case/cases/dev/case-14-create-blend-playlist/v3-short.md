1. Actor initiates a shared Blend creation request within the application.
2. System generates an invitation link protected by a temporary expiration window.
3. Recipient accesses the link and accepts the collaborative invitation.
4. System computes a mutual affinity score using the listening histories of both participants.
5. System constructs a combined playlist reflecting the shared musical preferences of both users.
6. System places the dynamic playlist into both users' libraries with automated daily refreshing enabled.
