**Title:** Fix Streak  
**Actor:** User  
**Description:**  
The sad green owl appears crying on the screen because the user forgot to practice yesterday. The user gets upset and wants their streak back. They click the button that says "Repair for 200 gems". The app checks their gems. If they have enough, Duo becomes happy again and the streak number goes back up to what it was before. Then the user goes back to the home screen.
