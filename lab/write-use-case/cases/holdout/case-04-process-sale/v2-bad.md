**Use Case:** Manage POS checkout
**Actors:** Cashier, Customer, Manager, Bank
1. Customer arrives and the cashier greets him.
2. Cashier scans barcodes and the system looks up the PRODUCT table.
3. If the code is wrong the system beeps.
4. The total is shown.
5. Customer pays.
6. Receipt printed.
*Also handles returns, refunds and end-of-day cash count.*
